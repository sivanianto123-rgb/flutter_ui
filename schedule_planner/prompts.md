# Schedule Planner — User Prompts

## Prompt 1 — 2026-03-26

Build an app using flutter to schedule stuff for the day.

Purpose and flow of the app:
1. The app should be able to plan users stuff of the day. For example, take notes, store checklists for the grocery, store recipies.
2. Schedules like meetings and appointments should be created by the user. Add required field and components for it.
3. App should be able to change dates as its choosen and each dates the app should be able to create new notes and schedules.
4. Completed can be tasks, meetings, chores can be strikedout and marked as completed.
5. Custom schedules can also be created with required fields and components.
6. Data should be stored and saved.
